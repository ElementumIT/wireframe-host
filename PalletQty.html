Unit Claiming App — Pallet Quantity Wireframe

Fourth screen (DataCollectionSteps=4: GetPalletQuantity). Source: UnitClaimingMainForm.cs, PalletInfoDisplay.cs. 880×520 client area.

Color Key

  • Next/Enter — primary (green)
  • Previous — disabled for Standard (gray)
  • Standard-specific disable (red)
  • Combo logic (amber)
  • Step/PalletInfoDisplay (blue)

Step: GetPalletQuantity

  • Input: numeric (positive integer)
  • Saves to: SkidQuantity AND ClaimedQuantity on current skid
  • Combo: after first qty → index=1, re-show PartNumber for skid 2
  • Advances to: GetSkidWeight (5)

⚠ Previous Disabled (Standard)

  • Ticket #84304 (7/3/2023)
  • When Previous step was PartNumber (2) OR SerialNumber (3)
  • Prevents accidental qty changes after part/serial entered
  • Other variations: Previous ENABLED

Combo Skid

  • After first qty → ComboSkidActiveSkidIndex = 1
  • Re-shows PartNumber for skid 2
  • Right panel shows "Qty1 / Qty2"
  • Previous ENABLED (no disable rule)

Right Panel: PalletInfoDisplay

  • 4-column tableLayoutPanel (15/20/18/47%)
  • 7 rows: Employee, Model, FAS Cell, Qty, Weight, Tolerance, Delta
  • Live updates as data collected
  • Labels bold when in data-entry mode
  • Combo shows "Val1 / Val2" for dual skids

Navigation

  • Previous → Serial Number (disabled for Standard from Part/Serial)
  • Next (Enter) → GetSkidWeight (5)
  • Enter = Next, Esc = Previous
  • Saves SkidQuantity + ClaimedQuantity
