Unit Claiming App — Part Number Entry Wireframe

Second screen (DataCollectionSteps=2: GetPartNumber). Source: UnitClaimingMainForm.cs, UnitClaimingMainFormController.cs. 880×520 client area.

Color Key

  • Next/Enter — primary action
  • Previous — enabled here
  • Combo-skid annotations (amber)
  • Step logic annotations (blue)

Step: GetPartNumber

  • Control: PartNumber (implements IDataCollectionControl)
  • Input: typed or scanned part number
  • Checkbox: "Is Product Monitoring Unit" — visible conditionally
  • On Next: save ModelNumber to current skid; combo handling; dup validation; advance to GetSerialNumber

Combo Skid Logic

  • Two UnitClaimingSkid records in model
  • ComboSkidActiveSkidIndex tracks 0 or 1
  • After first part+qty → index=1, re-show PartNumber
  • Dup model number validation across both halves
  • Previous disabled on skid 1 qty when coming from PartNumber

Navigation

  • Previous → back to Employee Authorization (enabled)
  • Next (Enter) → advances to GetSerialNumber
  • Enter = Next (AcceptButton), Esc = Previous (CancelButton)
