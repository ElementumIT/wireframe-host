Unit Claiming App — Skid Weight Wireframe

Fifth screen (DataCollectionSteps=5: GetSkidWeight). Source: SkidWeight.cs. 880×520 client area.

Color Key

  • Next/Enter — primary (green)
  • Previous — enabled (gray)
  • Conditional UI / Alerts (blue)
  • Complex conditional logic (amber)

Step: GetSkidWeight

  • Control: SkidWeight UserControl (427×369), implements IDataCollectionControl
  • Main input: tbSkidWeight (195×20) — manual or scale-read
  • Scale integration: PullWeightFromScale() on load; Re-read scale button
  • Partial Claim: checkbox + group with qty input (enabled conditionally)
  • Wood Pallet Weight: conditional override group with DB pre-fill

Conditional UI

  • Combo: Partial checkbox & group HIDDEN
  • Replacement Skid: forces partial, shows blue alert, disables checkbox
  • Extended Model Number: shows dual-model alert (e.g., ZD-DMBB-7MLC-24PC-AX + ZD-DMBB-7MLC-24PC)
  • Wood Pallet: shows override group with DB weight pre-filled
  • Debug: tbDebug visible only when config.EnableDebuggingHelpers

Validation & Events

  • tbSkidWeight_TextChanged → validation
  • tbPartialQty_Leave → saves partial qty
  • tbWoodPalletWeight_KeyPress/KeyUp → numeric only
  • Error providers for validation feedback

Navigation

  • Previous → Pallet Quantity (enabled)
  • Next (Enter) → SkidDataComplete (6)
  • Enter = Next, Esc = Previous

Special Cases

  • Replacement skid → forced partial, alert shown, checkbox disabled
  • Extended model number → dual-model alert (e.g., ZD-DMBB-7MLC-24PC-AX + ZD-DMBB-7MLC-24PC)
  • Wood pallet → override group with DB weight pre-filled
