Unit Claiming App — Wireframes

Sequential screens from the WinForms Unit Claiming application (ClaimingToWeb/ref-code-20260904)

Step 1

Main Menu

First screen on app launch. 11 plant-specific buttons, idle timeout status, ClickOnce version check. Navigate to Unit Claiming, Reprint, Low Volume, Combo, Kit Claiming, etc.

Step 2

Employee Authorization

Badge entry screen (DataCollectionSteps=1). Any 5-digit integer accepted. Loads security model, caches badge, sets PlantLocation. Disabled Previous, green Next advances to Part Number.

Step 6

Skid Weight

Skid weight entry (DataCollectionSteps=5). Scale integration (PullWeightFromScale, Re-read scale). Partial claim, replacement skid, extended model number, wood pallet override — all conditional UI. Debug console.

Step 7

Skid Complete

Terminal step (DataCollectionSteps=6). Review all data, variation-dependent Print/Save button. On success: print labels, save to DB, AfterSave() → back to Main Menu. History/reprint mode supported.

Data Collection Flow

GetEmployeeAuthorization (1)
    → GetPartNumber (2)
    → GetSerialNumber (3)
    → GetPalletQuantity (4)
    → GetSkidWeight (5)
    → SkidDataComplete (6)
    → (optional) GetMachineNumber (8), GetReturnableType (9), GetLocation (10), GetFASCell (11), GetSkidIdFromLicensePlate (12)

Special variations: Combo (dual skid), LowVolume, BoxLabel, StandardReprint, KitClaiming, MachineNumber, Location
